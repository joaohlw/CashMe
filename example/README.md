# 🎨 Protótipos de Interface Estáticos (Lojista)

Esta pasta contém páginas HTML estáticas de protótipo criadas durante a concepção da API para visualização e teste preliminar de fluxos do lojista:

- **`cadastro.html`**: Protótipo de formulário de onboarding de estabelecimento comercial.
- **`index.html`**: Protótipo de dashboard de métricas e regras de pontuação do lojista.
- **`list.html`**: Protótipo de listagem de estabelecimentos parceiros.

> [!NOTE]
> A aplicação oficial de produção completa está implementada em React + Vite dentro da pasta `src/`, contando com 21 telas integradas dinamicamente à API backend.
